因此，**2026 雅典经典马拉松真实官方导入完整示例目前尚未完成**。需要取得官方发布的当年路线文件、文件下载来源链接，以及能确认年份与赛事距离的官方说明。用户上传文件不自动认定为官方。路线变更需重新核实并更新源链接、日期和校验。

官方文件可在代码审查中转为静态 JSON `{ "points": [{ "lat": 0, "lon": 0, "ele": null }] }`（这是结构说明，不是赛道数据），提供至少两个真实坐标点，保留缺失高程为 null。在索引 courses 数组登记：

- year：具体举办年份
- distance：标称比赛距离（km）
- aliases：核实后的名称别名列表
- sourceUrl：实际官方文件来源 HTTPS 链接
- updatedAt：取得并核实数据的时间
- file：data/ 下的静态 JSON 文件路径
- sha256：该静态文件完整 UTF-8 字节的 SHA-256（不是坐标数组的摘要）

应用只请求同站点静态文件，不在浏览器抓取赛事官网。名称、举办年份、距离必须匹配，文件需通过摘要校验。缓存优先，未匹配或未取得官方文件时显示“暂无赛道数据”。GPX/KML/TCX 导入器不抓取任何赛事网站。

开发环境若需继续核实官方来源，需要允许访问 athensauthenticmarathon.gr、www.athensauthenticmarathon.gr，以及官方下载链接实际使用的域名。API 使用 api.opentopodata.org；网页浏览器自己的网络/CORS条件与开发环境代理不同。不能通过关闭 TLS、改代理或借用其他年份绕过来源核实。
